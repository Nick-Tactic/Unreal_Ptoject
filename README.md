# Прототип (UE 5.2, Blueprint)

Короткий 3D-прототип от третьего лица для домашних заданий курса (Gameplay Framework → AI → GameMode). Цель — закрыть требования ДЗ с минимальной механикой, без своего персонажа, инвентаря и «красивой» карты.

## О чём игра

Игрок ходит по маленькому многоярусному уровню из примитивов, подбирает предметы, открывает дверь ключом и доходит до выхода. На уровне есть аптечка, несколько collectables, один NPC на патруле и один охранник у зоны.

**Победа:** собраны нужные предметы (или использован ключ) и игрок входит в зону выхода.  
**Поражение:** здоровье кончилось → респавн на последнем чекпоинте (после ДЗ GameMode).

## Стек

- Unreal Engine **5.2**
- Шаблон **Third Person (Blueprint)** + Starter Content
- Герой: манекен шаблона, без своего скелета
- Взаимодействие: Overlap, не line trace
- AI: `AI Move To` и триггер-зоны; Behavior Tree не обязателен

Один `.uproject` на весь курс. Не создавать второй проект «с нуля», если Third Person уже есть (`Homework/Homework.uproject` или `Blueprint/Blueprint.uproject`).

## Структура Content

Новая логика — только в своих папках. Шаблон (`ThirdPerson/`, `StarterContent/`, `Characters/`) не переписывать.


| Папка                           | Назначение                                           |
| ------------------------------- | ---------------------------------------------------- |
| `Content/Maps/`                 | `Lvl_MainMenu`, `Lvl_Game`                           |
| `Content/Widgets/`              | Меню, «О игре», HUD, Start, статистика (Tab), победа |
| `Content/Blueprints/Character/` | Игрок, `HealthComponent` и др. компоненты            |
| `Content/Blueprints/Game/`      | GameMode меню и игры, GameState, PlayerState         |
| `Content/Blueprints/Pickables/` | Аптечка, collectables, ключ, дверь, выход            |
| `Content/Blueprints/AI/`        | NPC, враг, AI Controller (простой)                   |




## Запуск

1. Открыть `.uproject` в Unreal Engine 5.2.
2. Стартовый уровень: **Project Settings → Maps & Modes** → `Lvl_MainMenu`.
3. Play.
